
# Dataset Information

## Dataset
COCO 2017 (Common Objects in Context)

## Source
https://cocodataset.org/

## Documentation
https://docs.ultralytics.com/datasets/detect/coco/

## Task
Object Detection

## Target Classes
- Car
- Motorcycle
- Bus
- Truck

## Original Annotation Format
COCO JSON

## Original Dataset Splits
- Train: 118,287 images
- Validation: 5,000 images

## Annotation Type
Bounding boxes

## Dataset License
To be checked against the official COCO terms
and the conditions applicable to the selected images.

## Planned Preparation
- Select images containing target classes.
- Remove annotations belonging to other classes.
- Remap original COCO category IDs to four YOLO IDs.
- Create training, validation and test splits.
- Verify image and annotation integrity.
